## 🚀 新开发者上手步骤

### 第 1 步：阅读业务规则文档（必读）
打开 `docs/业务规则文档_给新开发者.md`，完整阅读。

### 第 2 步：导入源码到微信开发者工具
1. 安装微信开发者工具
2. 导入项目 → 选择 `miniapp-b2c/` 目录

4. ⚠️ `project.private.config.json` 是原开发者本机的，建议删除让开发工具重新生成

### 第 3 步：部署云函数
1. 云开发控制台 → 确认 envId = `cloudbase-d8gc0n57h3c535142`
2. 右键 `cloudfunctions/` 下每个云函数 → 上传并部署
3. ⚠️ 确认每个函数的 `config.json` 都有 `"timeout": 20`（默认 3 秒会超时）

### 第 4 步：登录后台
1. 登录 https://mp.weixin.qq.com
2. 让小程序管理员（Lisa）把你加为**项目成员 + 管理员**
3. 登录后：开发 → 云开发 → 确认能进入该环境
